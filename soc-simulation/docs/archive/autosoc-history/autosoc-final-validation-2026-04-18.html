6. Known limitations (documented, not blocking)

Live Caldera → endpoint telemetry → detection-alert chain is currently paused.
Actual root cause (discovered during this fix pass): the three GCE VMs (soc-linux-sv-1, soc-linux-ws-1, soc-linux-ws-2) had been SUSPENDED on the GCE side. They have been resumed — all three are now RUNNING. However, on one VM tailscaled was restarted during troubleshooting and its session token expired, so it now requires a one-time browser re-auth at the URL emitted by the VM (format: https://login.tailscale.com/a/<token>). Until that re-auth is completed, the three VMs cannot rejoin the Tailscale mesh and Elastic Agent cannot check in to the host Fleet Server at 100.123.104.92:18220. This is a 1-click human operation outside the AutoSOC scope. The demo uses the 3,016-alert historical corpus plus the seeded live cycle, which is sufficient to demonstrate every AutoSOC loop.
  • Hourly charts on Overview ("Alert Triage Volume", "Completed Outcomes") read empty because they window to the last hour and depend on live alert ingestion.
  • 59 legacy rejections reference UUIDs never registered — not salvageable retroactively; new agent recs now flow through correctly (see the 2 Applied, 38 auto-applied, and 545-row decision trail).
