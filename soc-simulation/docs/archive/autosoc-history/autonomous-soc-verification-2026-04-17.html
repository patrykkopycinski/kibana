5 Expected-empty surfaces (legacy-data residue)

Not a regression. Four KPIs on Overview and the Triage Results table render empty because pre-migration .soc-triage-results docs still use the old batch envelope. The UI (correctly) queries the new flat per-classification shape introduced by the T1 flatten fix. Until one new sweeper cycle runs, those docs don't exist, so the KPIs are legitimately zero.

The same pattern holds for .soc-recommendations terms aggregations: legacy docs don't have recommendation_type or details.track populated, so those ES aggs return empty buckets even though 64 recommendation cards render fine on the Recommendations tab.

6 Governance gates — live proof

T5 gates are executing.
