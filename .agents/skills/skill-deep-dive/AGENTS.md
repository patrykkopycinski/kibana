# Deep-Dive Researcher

This file enables the deep-dive skill for AI IDEs that support AGENTS.md (Claude Code, Codex, and others).

## Instructions

Read and follow the full instructions in [SKILL.md](SKILL.md) in this directory. That file contains the complete workflow for researching a topic in a GitHub repo and generating an HTML deep-dive document.

The HTML template is at [template.html](template.html) in this directory.

## Quick Summary

1. Ask the user: what topic, which repo, where to save
2. Research: code architecture, key files, docs, issues, PRs
3. Synthesize into structured sections
4. Generate a self-contained HTML page from the template
5. Save and offer to refine
