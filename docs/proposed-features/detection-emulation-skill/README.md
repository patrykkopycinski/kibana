# Detection Emulation Skill — Working Folder

This folder is a workspace for the Epic
[`elastic/security-team#15974`](https://github.com/elastic/security-team/issues/15974)
that productizes James Spiteri's hackathon SMEAGOL agent into a Tech-Preview
**Detection Emulation Skill** inside Agent Builder.

## Files

- `SMEAGOL-source-transfer.sh` — the original `bash` transfer script generated
  out of James's hackathon cluster. It contains the complete shape of the
  prototype: 9 Workflow YAMLs, 17 ESQL/Workflow tools, and the agent system
  prompt. **It is checked in as a frozen reference** so every agent job
  branched off this plan can read the source-of-truth without having to
  guess at what SMEAGOL did. **DO NOT** copy code or credentials out of it
  verbatim — see the security risks called out in the plan's `proposal.md`
  / `design.md`.

## What is committed here vs. what lives elsewhere

- **Here (committed)**: design docs, this README, frozen reference materials.
- **Plan artifacts (`openspec/changes/<plan-name>/`)**: proposal, specs,
  design, tasks — generated by the AO plan orchestrator and committed by
  the orchestrator's own agents.
- **Source code**: lands under `x-pack/platform/plugins/shared/onechat/`
  (or wherever Agent Builder ultimately lives) and other plugins as the
  plan progresses.

## Contract with the SMEAGOL prototype

We are NOT lifting SMEAGOL as-is. We are extracting:

1. The agent system prompt (heavily revised — see risk register)
2. The two-mode emulation model (Real Execution + Log Injection)
3. The ECS document templates for log injection
4. The emulation history schema (re-shaped under `.kibana_security_*`)

We are explicitly REJECTING:

1. Hard-coded Basic-Auth credentials in workflow YAMLs
2. Default-allow on production hosts
3. Use of internal Kibana APIs without versioned wrappers
4. Direct `/api/endpoint/action/execute` exposure to skill callers
   without RBAC, an allowlist, and audit logging

See the plan's `proposal.md` and `design.md` for the full risk register
and the guardrails each one maps to.
