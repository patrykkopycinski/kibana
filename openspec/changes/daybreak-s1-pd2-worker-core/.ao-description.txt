Research this session (subagent explore, cited below) resolves A-1's two open sub-questions:
1. **Reason-phase invocation mechanism**: the workflow engine's generic `type: connector` step (used for the stub in PD-1) is NOT how Agent Builder agents are invoked. A purpose-built step type `ai.agent` exists (`x-pack/platform/plugins/shared/agent_builder/common/step_types/run_agent_step.ts:21`, registered via Workflows Extensions at `.../server/plugin.ts:128-131`), with a real prior-art example targeting an alert-triage agent at `src/platform/packages/shared/kbn-workflows/spec/examples/invoke_agent.yml:16-21`. Raw connector sub-action steps for AI (`inference.*`, `gen-ai.*`) are explicitly deprecated for workflow use in favor of the `ai.*` family (`src/platform/packages/shared/kbn-workflows/spec/deprecated_step_metadata.ts:53-58`).
2. **Reusable skill**: `x-pack/solutions/security/plugins/security_solution/server/agent_builder/skills/alert_analysis/alert_analysis_skill.ts:23-148` (`id: 'alert-analysis'`) already encodes a full triage-disposition workflow (True/Benign-True/False-Positive/Needs-More-Data) wired to `security.alerts`, `security.security_labs_search`, `security.entity_risk_score`, and an inline related-alerts tool. This is the skill PD-2's Reason phase (hook 4) should invoke via `ai.agent`, not a from-scratch skill.

Also confirmed by the same research: the S0 `server/client/evidence/` and `server/client/proposals/` modules referenced by the feature's `intent` field as "already exist, uncommitted, REUSE don't reimplement" are in fact **stale build artifacts only** — `target/types/**/*.d.ts` exists for both, but `git log --all -- "server/client/*"` returns zero commits and `git stash list` is empty on the `daybreak-spike` worktree. The `.ts` source was never committed and cannot be recovered from git history. **This plan corrects that: PD-2 must re-author `server/client/evidence/` and `server/client/proposals/` from scratch**, using the `.d.ts` files purely as a type-shape reference (documented in Impact below), not as a scaffold to extend.
