The Autonomy Contract

Six principles enforced by Wave 1 infrastructure. Each has a live signal in the cluster below.

1
Auto-apply is the default path
A mutation_intent that satisfies every gate transitions to applied without a human in the loop. Observed: 32 auto-applied vs 4 routed for review over 7 days.
2
Human review is the exception path
Only used when the applier gate cascade fails in a way the system cannot resolve (unknown op, high-blast-radius artifact, trust tier too low). Target ≤ 5% of decisions — currently 2.5%.
3
Every action is reversible
.soc-snapshots captures the pre-mutation artifact state before any apply. soc-post-apply-observer watches KPIs and restores the snapshot if TP regression, alert spike, or suspicious silence is detected. 6 rollbacks successfully executed this week.
4
Autonomy is continuous
The backtester runs inside the applier workflow, the trust scorer runs every 30 minutes, and the post-apply observer runs every 5 minutes. No approval window, no business hours.
5
Trust is measured, per agent
soc-trust-scorer computes per-agent trust scores and tiers them (trusted · probationary · observing · quarantined). The applier checks tier before auto-applying. Example caught: experimental-tuner-v3 tier quarantined (3 rollbacks, score 0.35).
6
The operator monitors, does not gate
The Autonomy Activity Feed tab (public/autonomous_soc/pages/autonomy_feed_panel.tsx) is read-only. Operators see every gate decision, every backtest verdict, every rollback — but the system does not wait for them.

curl -u elastic:changeme "http://localhost:19200/.soc-autonomy-decisions/_search?size=0" \
  -H 'Content-Type: application/json' -d '{
  "query": {"range": {"@timestamp": {"gte": "now-7d"}}},
  "aggs": {
    "auto_apply": {"filter": {"term": {"auto_applied": true}}},
    "required_human": {"filter": {"term": {"required_human": true}}},
    "applied": {"filter": {"term": {"final_status": "applied"}}},
    "rolled_back": {"filter": {"term": {"final_status": "rolled_back"}}},
    "by_status": {"terms": {"field": "final_status", "size": 20}},
    "by_gate": {"terms": {"field": "first_failing_gate", "size": 10, "missing": "(passed)"}},
    "by_tier": {"terms": {"field": "trust_tier", "size": 10}}
  }
}'
Aggregation — backtest verdicts + average FP reduction / TP preservation
